```

dI=r*Io=0.9A

电感饱和电流(取20%余量):Isat=(1+20%)*Imax=4.14A
dI=[Voff*(1-D)]/(f*L)
其中，芯片选用TPS5430，频率f固定为500K
电感值L=[Voff*(1-D)]/(f*dI)=[5V*(1-0.179)]/(500K*0.9)
L=9.12uH
选择标准值偏大的10uH电感，1040封装，Isat=6.5A
```
